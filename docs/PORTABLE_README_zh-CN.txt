InkHorn · Windows x64 便携版
版本：1.0.2
构建日期：2026-11-08

解压到可写目录，双击 InkHorn.exe 即可运行。
无需另装 Python、PDFium DLL 或 VC++ 运行库。
主要验证平台：Windows 11 x64；Windows 10 x64、ARM64 未独立验证。

打开、批注与保存
Ctrl+O 打开 PDF；Ctrl+S 保存，Ctrl+Shift+S 另存为。
顶部文件名可点击展开文件列表；Ctrl+Tab 切换文档，Ctrl+W 关闭文档。
使用笔、荧光笔或形状进行批注；Ctrl+Z / Ctrl+Y 撤销、重做。
默认启动使用指针；在指针状态下使用笔会切换到笔 1，鼠标或触摸板可恢复指针。
压感笔建议在驱动中启用 Windows Ink。

窗口拖出与合并
从顶部文件列表拖出文件项，即可生成独立窗口。
普通窗口保持尺寸；系统最大化或 F11 全屏时，新窗口宽高各为原窗口的 60%。
普通窗口可直接拖动文件标题移动；点击松手才展开列表。
拖动窗口时，把鼠标停在另一个窗口的文件标题处 300 毫秒，自动展开列表。
蓝色横线表示插入位置，松手放进列表即可合并；多份文件保持原顺序整体插入。
未保存笔迹、撤销重做和阅读位置会保留，合并后激活拖入窗口原当前文件。
松手在列表外或按 Esc 取消，会保留独立窗口。
正在打开、保存或处理关闭确认时，请先等待相关操作完成。

文字搜索与复制
Ctrl+F 或工具栏放大镜打开正文搜索；框内 Ctrl+A 全选。
Enter / Shift+Enter、上下箭头切换匹配，Esc 关闭搜索。
指针工具可拖选单页正文，Ctrl+C 复制，并遵守 PDF 复制权限。
支持普通中英文换行搜索；不提供 OCR，不支持跨页拖选。
每页最多读取 100,000 个字符，最多显示 2,000 项搜索结果；达到限制时会提示。

个人数据与升级
设置、最近文件、阅读位置、恢复缓存和日志保存在 EXE 同级 InkHorn-data 文件夹。
该目录首次运行时自动创建，程序所在目录需要可写。
升级前关闭程序，在原目录替换 InkHorn.exe，保留 InkHorn-data。
迁移个人状态时同时复制该文件夹；分享程序时请只分发官方发布包。
正常保存后的批注包含在 PDF 中，分享笔记只需分享保存后的 PDF。
恢复记录不能代替主动保存；隐藏笔迹只影响本程序显示。

其他快捷键
下列为默认按键，可在“设置 → 快捷键”中修改。
Ctrl+滚轮 / Alt+滚轮 缩放；Shift+滚轮 横向移动；普通滚轮纵向移动。
空格+左键拖动或中键拖动，可同时横向、纵向平移，不修改笔迹。
触摸板标准双指横纵滑动，双指捏合缩放；触摸屏直接双向拖动。
捏合与实体 Ctrl+滚轮统一缩放，不再区分 Ctrl 的输入来源。
笔精准导航连续移动时锁定单轴，停顿约 200 毫秒后重新选轴，可不抬笔横移后转纵移；不附加尾随惯性。
侧边空白处大幅拖动只纵向移动及惯性，保留普通箭头光标。
笔坐标路径按视口位移 1:1 移动；驱动只有行命令时使用单屏幕像素小步，无法保证真实笔位移比例。
严格跟手可将侧键映射为空格或中键。保留驱动可查询的横向范围；本机本轮调整已通过用户复测。
不同设备和驱动的表现仍需验证；普通侧键/橡皮标志仍使用临时橡皮。
输入诊断分别显示滚动消息名称、增量或命令，便于区分横纵输入。
松开空格后当前接触平移到抬起，下一次落笔恢复原工具。
Ctrl+G 页码跳转；F11 全屏。
Delete 删除选中对象；1 / 2 / 3 选择工具 / 笔 1 / 笔 2。
Ctrl+Shift+D 启停输入诊断；Ctrl+Shift+L 打开日志目录。
完整第三方许可已嵌入 EXE，可从“设置 → 关于与说明 → 第三方许可”查看。

设置与快捷键
从功能菜单“设置…”或默认 Ctrl+, 打开设置。
常规页提供左手模式、阅读调暗、工具栏拖动/位置重置、个人数据及诊断目录入口。
快捷键页支持 25 项操作，点击一项后按新组合键；冲突时会提示。
Esc 取消录入，Backspace 清除此项；列表末尾可恢复全部默认快捷键。
支持字母、数字、Delete、F1–F12（F3 除外），可搭配 Ctrl / Shift。
另支持 Ctrl+Tab、Ctrl+, 及其 Shift 组合；Alt / Windows 组合键不参与自定义。
Ctrl / Alt+滚轮缩放、Shift+滚轮横移与空格拖动为固定导航操作。
文本框保留输入、复制粘贴、全选与搜索跳转等用途。
滚轮/触摸滑动列表，左右箭头或 Tab 切换分类，上下箭头选择，Enter 操作。
设置自动保存，并同步到同一程序的其他窗口；旧版个人设置可直接继续使用。
侧键保留原有临时橡皮行为；空格可临时平移，暂不提供任意工具的“按住切换”自定义。

开发版说明
橡皮为整笔擦除，已有笔迹暂不支持缩放、旋转或修改样式。
不同 DPI 多屏、不同触摸板/笔驱动和复杂 PDF 的表现仍需持续验证。
