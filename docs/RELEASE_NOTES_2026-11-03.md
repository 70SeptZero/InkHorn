# InkHorn V1.0.1 — 窗口拖出合并与正文搜索

2026-11-03 · Windows x64 · 开发预览版

本版新增文件列表拖出窗口、悬停合并，以及 PDF 正文搜索与单页文字复制，并改进多屏窗口交互和触摸板输入识别。

## 新增

- **窗口拖出与合并**：从顶部文件列表拖出文件项创建独立窗口；将鼠标停在另一个窗口的文件标题处 300 毫秒，自动展开列表，按蓝色插入横线松手合并。多份文件按原顺序整体插入，并激活拖入窗口原本正在阅读的文件。
- **会话保留**：窗口之间移动文档时，保留未保存笔迹、撤销重做和阅读位置；关闭原窗口后，独立窗口仍可使用。
- **同窗口接收文件**：同一路径的程序再次打开 PDF 时，默认交给已有窗口；已打开的同一文件会定位到所属窗口。
- **正文搜索**：按 `Ctrl+F` 或点击工具栏放大镜搜索，支持普通中英文跨行、英文行末断词，使用 `Enter` / `Shift+Enter` 或箭头切换匹配项。
- **文字选择与复制**：使用指针拖选单页 PDF 正文，按 `Ctrl+C` 复制，并遵守 PDF 文档的复制权限。

## 改进与修复

- 文件标题支持点击展开列表、拖动移动窗口，两种操作按系统拖动阈值区分。
- 最大化或 F11 全屏时，拖出的新窗口宽高各取原窗口的 60%；鼠标保持在新窗口标题栏宽度约 1/4、垂直居中的位置。
- 修复副屏顶部无法触发合并、展开列表后拖动窗口被目标窗口遮挡的问题；提供标题高亮、缩小与半透明反馈。
- 调整搜索框的全选、计数右对齐、计数右侧留白和按钮垂直对齐。
- 改进 Windows 明确报告的触摸板输入识别，并在输入诊断中记录设备来源。
- 正文按页在后台读取，渲染与保存任务优先；窗口迁移直接保留内存会话，减少重复打开文档的开销。

## 下载与升级

下载 `InkHorn-1.0.1-windows-x64.zip`，解压到可写目录后运行 `InkHorn.exe`。也可单独下载 `InkHorn.exe`；运行时无需另装 Python、PDFium DLL 或 VC++ 运行库。

升级前关闭程序，在原目录替换 `InkHorn.exe`，保留 EXE 同级的 **`InkHorn-data/`**，即可继续使用个人设置、最近文件和恢复记录。发布包不包含个人数据。

附件中的 `SHA256SUMS.txt` 可用于核对下载文件的 SHA-256。

## 验证与当前限制

- Windows 11 x64 上，Release、Debug 各 12 项自动检查通过，覆盖笔迹历史、恢复存储、输入、窗口实例转交、PDF 保存重开、文字搜索/选择、界面、性能与绘制质量。
- 已验证主副屏真实坐标下的目标发现、列表展开和消息级合并；本轮窗口与搜索交互经用户复测确认。
- 两块测试屏幕均为 150% 缩放；不同 DPI 组合、更多笔/触摸板驱动、复杂 PDF 与跨阅读器批注显示仍需继续验证。合成性能检查不等于真实设备到屏幕的端到端延迟。
- 正文搜索依赖 PDF 文字层，不包含 OCR；文字拖选限单页。单页最多读取 100,000 字符，最多显示 2,000 项搜索结果，达到限制会提示。
- 橡皮目前为整笔擦除；已有笔迹支持移动与删除，暂不支持缩放、旋转或修改颜色、线宽。
- Windows 10 x64 为兼容目标，ARM64 尚未验证。本版仍为开发预览版。
