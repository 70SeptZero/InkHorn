# InkHorn

面向手写笔的 Windows PDF 阅读与批注工具。

InkHorn 将连续页面阅读、压感书写与 PDF 批注保存放在一个原生桌面应用中，适合阅读讲义、标记资料和手写笔记。采用 C++20、Win32、Direct2D / DirectWrite 与 PDFium 构建，中文界面，支持单 EXE 便携运行。

**当前版本：1.0.2 · 开发预览版。** 阅读、书写和保存的基础流程已实现；真实设备手感、复杂文档性能及跨阅读器兼容性仍在持续验证。见 [V1.0.2 更新说明](./docs/RELEASE_NOTES_2026-11-04.md)。

## 功能

| 方向 | 已支持 |
| --- | --- |
| PDF 阅读 | 默认同窗口打开多份 PDF、文件列表拖出新窗口、悬停标题拖入合并、多文档切换、连续页面、页码跳转、缩放、全屏与阅读位置记忆 |
| 正文文字 | 右上角搜索框、全文逐页查找与高亮、上下项跳转、指针单页拖选与复制 |
| 手写批注 | 两支独立配置的压感笔、线宽与颜色设置、自由荧光笔、自定义 HEX 颜色 |
| 图形与编辑 | 矩形、椭圆、直线、箭头，整笔擦除，选中后移动或删除，撤销与重做 |
| 输入与布局 | Windows Pointer / Windows Ink、笔侧键临时橡皮、鼠标与笔自动切换工具、左手模式、可拖动工具栏 |
| 阅读手感 | 双向平移、触摸板捏合与横纵滚动、Ctrl / Alt 滚轮缩放、Shift 滚轮横移、笔精准单轴导航与停顿换轴 |
| 设置 | 统一的常规、快捷键、关于与说明页面；快捷键录入、冲突检查、清除与恢复默认 |
| 保存与恢复 | 保存原文件或另存为 PDF、批注显隐、后台恢复记录、工具偏好记忆 |

笔迹会随批注写入 PDF，同时保存标准 Ink 轨迹、矢量外观和 InkHorn 的可编辑数据。重新用 InkHorn 打开后可继续编辑；在其他阅读器中的显示仍需结合具体软件验证。

## 开始使用

使用构建得到的 `InkHorn.exe`，将它放在可写目录中双击运行。正式 Release 构建静态链接 PDFium 和 MSVC 运行库，图标与第三方许可文本嵌入程序，运行时无需另装 Python、PDFium DLL 或 VC++ 运行库。

当前主要验证平台为 **Windows 11 x64**；Windows 10 x64 是兼容目标，ARM64 尚未验证。源码仓库不包含已忽略的 `dist/` 和构建产物，源码编译步骤见下文。

1. 点击首页“打开 PDF”，或按 `Ctrl+O` 选择文档。
2. 选择笔、荧光笔或形状工具，在页面上批注。再次点击已选工具可展开颜色、线宽或形状设置。
3. 使用整笔橡皮擦除笔迹，或切换选择工具后移动、删除已有对象。
4. 按 `Ctrl+S` 保存，或按 `Ctrl+Shift+S` 另存为。

再次双击 PDF 时，同一路径的 InkHorn 程序会将文件交给已有窗口；同一份 PDF 已打开时会定位到它所在的窗口。点击顶部文件名打开“已打开文件”列表，将文件项拖出列表即可移到独立窗口，保留未保存笔迹、撤销重做与阅读位置。未最大化的普通窗口拖出时保持原窗口尺寸；系统最大化或 F11 全屏时，新窗口的宽、高各为原窗口的 60%。新窗口以鼠标为锚点，鼠标落在窗口宽度约 1/4、标题栏垂直中间的位置；靠近屏幕边缘时优先保留这个落点，窗口可部分超出屏幕。关闭原窗口后，独立窗口仍可继续使用；文档正在打开或保存时暂不可拖出。

普通窗口支持用鼠标直接拖动文件标题来移动整个窗口：点击松手才展开列表，移动超过系统拖动阈值则开始拖窗，不会同时展开列表。再次点击已展开列表的标题可关闭列表，按 Esc 可取消尚未开始的标题拖动。

拖动独立窗口的标题栏，把鼠标指针移到另一窗口左上角的文件标题处，目标标题会高亮，拖动窗口略微缩小并半透明；停留 300 毫秒后，文件列表自动向下展开，拖动窗口保持在目标窗口前面。列表中的蓝色横线指示插入位置，在文件项的上半部或下半部移动可选择插到该文件之前或之后。松手放到列表内，即可按横线位置将拖入窗口的全部文件连续加入，保留两边文件各自的顺序，并激活拖入窗口原本正在阅读的文件。离开目标、按 Esc 取消或松手在列表外，会恢复窗口外观并保留独立窗口。任一待合并文档正在打开或保存，或窗口正在处理编辑/关闭确认时，暂不合并。

拖动仅做标题与列表命中检测，悬停期间复用同一个列表面板；窗口缩小预览不改变文档倍率，也暂停发起新的 PDF 渲染和文字提取。合并直接移动内存中的会话，共享 PDF 与存储队列，不通过保存再重开来传递文档。窗口创建、首次菜单绘制与移入后的图形资源重建仍有一次性开销，复杂文档与多屏不同 DPI 的实际拖动体验需真机确认。

不同目录的 InkHorn EXE 各自管理窗口会话，开发版和便携分发版互不接管。系统 PDF 文件关联也需要指向本次使用的新版 EXE。

使用压感笔时，请在驱动中启用 Windows Ink。侧键临时橡皮依赖设备报告的按键标志；若侧键被驱动映射为快捷键，需检查驱动配置。

### 平移与缩放

放大页面后，触摸板按标准双指横向/纵向滑动；触摸屏可直接双向拖动。鼠标按住 `空格` 再左键拖动，或直接按住中键拖动，可同时横向、纵向移动页面，即使当前选中的是笔、橡皮或选择工具，也不会移动或擦除笔迹。指针工具在页面内正文/已有笔迹之外的普通拖动支持双向平移；页面外侧空白处的大幅拖动只沿纵向移动，使用普通箭头光标。

普通滚轮纵向滚动；`Ctrl+滚轮` 和 `Alt+滚轮` 缩放，`Shift+滚轮` 横向移动（向上滚向左，向下滚向右）。触摸板双指捏合沿用原生缩放手势或 Ctrl 滚轮路径，驱动模拟 Ctrl 按键时也统一缩放。横向滚轮及触摸板高精度横向消息保留系统方向和小增量，两个方向可同时平滑移动；到达某一方向边缘不会截断另一方向。

笔侧键“移动画布”用于精准导航：起拖累计少量位移后锁定横向或纵向，连续运动时保持该方向；停顿约 200 毫秒后重新选轴，可按住侧键先横移、停顿、再纵移，无须抬笔。立即应用输入，不附加平滑尾随或松手惯性。侧边空白处只保留纵向大幅移动与纵向惯性。笔坐标拖动按视口位移 1:1 移动，PDF 倍率不放大拖动距离；到边缘后反向可立即移动。

当前接收标准横纵滚轮、Pointer 滚轮、旧式 WM_HSCROLL/WM_VSCROLL、中键及空格加笔拖动，同时提供驱动可查询的原生横向范围和位置。2026-11-08 用户已确认本轮捏合、笔横移及精准导航调整无问题；其他设备和驱动仍需持续验证。驱动若只发送离散行命令，无法据此还原笔的真实位移；精准模式将每个行命令收窄为一个屏幕像素，绝对位置命令按位置差移动，滚轮量按驱动增量即时应用。需要严格按笔坐标跟手时，可将侧键映射为空格或中键使用坐标拖动。普通侧键/橡皮标志仍为临时橡皮；松开空格后当前接触平移到抬起，下一次落笔恢复原工具。


鼠标处于指针工具时，笔进入感应范围会自动切换到笔 1；若已手动选择其他绘图工具，则沿用所选工具。笔输入后重新进行普通鼠标或触摸板指针操作会回到指针工具；平移和滚轮导航保留当前工具。触摸板按 Windows 报告的输入来源识别；笔接触期间混入的鼠标消息不会切断笔画，具体驱动行为仍需真机确认。

按 `Ctrl+F` 或点击工具栏的放大镜打开右上角搜索框，输入关键词后自动逐页查找；框内 `Ctrl+A` 全选输入内容，`Enter` / `Shift+Enter` 或上下箭头切换匹配项，`Esc` 关闭。匹配计数位于输入区域右侧，箭头和关闭按钮与输入框垂直居中。支持普通英文换行、中文跨行和英文行末断词；显式空行及明显段间距按段落边界处理，不跨页拼接搜索。PDF 通常没有可靠的段落语义，多栏、特殊排版和缺失字符映射的文档可能需要调整关键词。

使用指针工具在正文上拖动可选择同一页的文字，按 `Ctrl+C` 复制（保留 PDF 文字层中的换行，并遵守文档复制权限）。已有笔记优先支持选中移动；在文字以外拖动可平移页面。扫描件及手写笔迹需要 OCR 才能作为正文搜索或复制，当前未提供 OCR。

文字按页在 PDF 后台队列读取，渲染与保存任务优先，正在书写时暂停安排下一页文字任务；不会在打开文档时建立全文索引。每个文档最多缓存 8 页文字；单页超过 100,000 字符会跳过，搜索最多显示 2,000 项，跳过页与结果上限会显示在搜索框中。

### 设置

点击左上角功能菜单中的“设置…”，或按默认快捷键 `Ctrl+,` 打开设置。页面沿用软件的浅色圆角面板、灰蓝文字与蓝色强调色，分为三个分类：

- **常规**：左手模式、阅读调暗、工具栏允许拖动与位置重置、个人数据目录，以及输入诊断和诊断目录入口。
- **快捷键**：可修改 25 项操作的按键，包括文件、编辑、搜索、工具切换、全屏和设置入口；适合宽度、隐藏笔记也可自行绑定。点击一项后按下新组合键，冲突时会提示占用的操作；`Esc` 取消录入，`Backspace` 清除此项，列表末尾可恢复全部默认快捷键。
- **关于与说明**：基本用法、便携数据说明及完整第三方许可入口，取代原来的“设置与说明”面板。

设置页支持滚轮和触摸滑动，`←` / `→` 或 `Tab` 切换分类，`↑` / `↓` 选择项目，`Enter` 操作；`Esc` 取消按键录入或关闭页面。设置自动保存，阅读与工具栏偏好和快捷键会同步到同一程序的其他窗口。

支持字母、数字、`F1`–`F12`（`F3` 除外）、`Delete`，可搭配 `Ctrl` / `Shift`；另支持 `Ctrl+Tab`、`Ctrl+,` 及其 Shift 组合。`Alt` / Windows 组合键不参与自定义；`Ctrl+滚轮` / `Alt+滚轮` 缩放、`Shift+滚轮` 横移与空格拖动为固定导航操作。`Esc`、搜索跳转与文本框中的输入、复制粘贴、全选等保留原本用途。文档操作快捷键在阅读区域生效；文本框中仅转发带 Ctrl 的查找与设置快捷键，且不覆盖文本编辑按键。旧版个人设置可直接继续使用。

### 文件与个人数据

设置、最近文件、阅读位置、恢复记录和诊断日志保存在 **EXE 同级的 `InkHorn-data/`**，因此程序所在目录需要可写。迁移个人状态时，将这个目录与 EXE 一起复制；分享已保存的批注时，只需分享 PDF。

保存采用临时文件写入、重开检查和替换原文件的流程。恢复记录用于异常退出后找回未保存笔记，不能代替主动保存；源 PDF 在外部发生变化时，程序会拒绝静默覆盖。应用内隐藏批注只影响当前查看，正常保存的 PDF 仍显示笔记。

## 从源码构建

### 环境要求

- Windows x64。
- Visual Studio 或 Build Tools，安装“使用 C++ 的桌面开发”与 MSVC x64 工具链。当前开发环境使用 Visual Studio 2026。
- **Windows SDK 10.0.28000.0**：当前锁定的 PDFium 构建脚本会检查此版本。
- CMake **3.25 或更新版本**、Ninja、Git for Windows、Python 3。
- PowerShell；CLion 可选。

正式 PDF 功能使用 MSVC ABI 的静态 PDFium，CLion 中应选择 **Visual Studio / amd64** 工具链。

### 1. 准备 PDFium

在仓库根目录（即包含 `CMakeLists.txt` 的 `InkHorn` 目录）打开 PowerShell，执行：

```powershell
.\scripts\Prepare-Pdfium.ps1 -CheckOnly
.\scripts\Prepare-Pdfium.ps1 -Jobs 4
```

脚本根据 [`dependencies.lock.json`](./dependencies.lock.json) 获取锁定版本的 PDFium 与 depot_tools，并从源码构建静态库。首次准备需要联网下载源码及工具，耗时和磁盘占用明显高于主程序构建。

依赖源码和缓存位于 `third_party/source/`，生成的 SDK 位于 `third_party/pdfium/`，两者都已加入忽略规则。依赖源码路径不能含空格；必要时通过 `-DependencyDirectory` 指定其他目录。需要代理时可传入 `-Proxy http://127.0.0.1:端口`；依赖已完整同步、仅重新编译时可使用 `-SkipSync`。

### 2. 编译并运行测试

继续在仓库根目录执行：

```powershell
.\scripts\Build.ps1 -Preset release -Test
```

脚本会载入 Visual Studio amd64 开发环境，执行 CMake 配置、编译和 CTest。CMake 与 Ninja 可放入 `PATH`，也可通过 `CLION_HOME` 或脚本参数 `-CMake`、`-Ninja` 指定位置。

窗口界面冒烟由 `ui_smoke_runner` 在独立 Windows 桌面运行，不切换当前桌面，分别检查无遮挡展开和遮挡阻止合并，避免其他应用影响测试前提。运行环境须允许创建桌面；受限沙箱可能返回 `CreateDesktop failed: 5`，此时需要在允许该操作的环境复跑，不能将权限失败视为测试通过。2026-11-08 的 Release、Debug 构建成功，完整 CTest 在沙箱外运行各 15/15 通过。

Release 程序输出到：

```text
build/release/bin/InkHorn.exe
```

需要调试版本时执行：

```powershell
.\scripts\Build.ps1 -Preset debug -Test
```

Debug 输出到 `build/clion-debug/`。在 CLion 中打开仓库根目录的 `CMakeLists.txt`，选择 Visual Studio / amd64 工具链，加载 `release` 或 `debug` 预设并运行 `InkHorn` 目标。

### 3. 整理分发文件

在仓库根目录执行以下命令；`cmake` 需在 `PATH` 中，也可替换为其完整路径：

```powershell
cmake --install build/release --prefix dist
```

生成的 `dist/InkHorn.exe` 可单独复制运行。首次分发无需携带源码、构建缓存或个人 `InkHorn-data/`。

## 当前限制

- 橡皮目前为整笔擦除；局部擦除、套索和多选尚未完成。
- 已有笔迹支持移动、删除，暂不支持缩放、旋转、复制或修改颜色与线宽。
- 正文选择目前限单页，不支持跨页拖选；扫描件 OCR、文字吸附批注高亮、目录与书签、干净副本导出、停顿拉直、完整无障碍支持及外来批注编辑尚未完成。
- 本机触摸板捏合、Wacom One 横移、侧边仅纵向拖动及停顿换轴已获用户确认；不同设备、驱动与混合 DPI 仍需验证。见[精准导航与缩放调整](./docs/PRECISE_NAVIGATION_2026-11-08.md)。
- 加密 PDF 的密码输入界面尚未实现；签名 PDF 或不允许批注的文档会进入保护性拒绝保存状态。
- 真机长时间书写、复杂 PDF 性能以及 Adobe / Edge 等阅读器的批注显示仍需继续验证，历史报告的偶发停顿尚不能视为完全解决。

2026-10-30 的开发验证记录为 Release、Debug 各 12 项自动检查通过，覆盖笔迹与历史、恢复存储、输入、窗口实例转交、PDF 保存重开、文字搜索与选择、界面冒烟及绘制质量等。新增检查覆盖独立子进程转交中文/空格路径、搜索框全选与控件对齐、工具栏搜索，以及拆分后保留笔迹历史和原窗口关闭后的生命周期。合成性能测试不代表复杂文档或真实手写设备到屏幕的端到端延迟；当前检出的代码可通过上述 `-Test` 命令重新验证。
